# SunsetGuard v0.1.1

SunsetGuard v0.1.1 is a documentation and release-hygiene update. Runtime analysis behavior and public data contracts are unchanged from v0.1.0.

## Changes

- Replace internal development diaries with concise public status, roadmap, and current design decisions.
- Remove local workspace identifiers and repository-internal process notes from the public project tree.
- Preserve application evidence, security boundaries, validation results, and known limitations.
- Fix the packaged README link to the public implementation specification.

## Install from the release bundle

Verify `SHA256SUMS.txt`, extract `sunsetguard-local-trial.tgz`, then run:

```sh
cd sunsetguard
pnpm install --prod --frozen-lockfile --ignore-scripts
node dist/cli/bin.js --help
```

The archive contains compiled output, corresponding TypeScript source, a locked dependency graph, an MIT license, the implementation specification, and synthetic examples. It does not contain `node_modules`, a Node runtime, caches, reports, or downstream project source.
