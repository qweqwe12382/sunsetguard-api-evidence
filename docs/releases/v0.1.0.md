# SunsetGuard v0.1.0

SunsetGuard v0.1.0 is the first tagged source and local-trial release of the read-only JS/TS API reference evidence CLI.

## Highlights

- Analyze an explicit local directory or pinned public GitHub commit without executing consumer code.
- Distinguish import-only, value-reference, type-reference, and direct-reexport evidence.
- Keep ambiguous attribution, unsupported syntax, parse errors, source changes, and resource limits visible as gaps.
- Produce JSON, text, or Markdown reports while keeping JSON stdout machine-readable.
- Reuse verified snapshots and analysis through a bounded cache with offline replay.
- Run the complete type, lint, build, and offline test suite on Linux and Windows CI.

## Install from the release bundle

Verify `SHA256SUMS.txt`, extract `sunsetguard-local-trial.tgz`, then run:

```sh
cd sunsetguard
pnpm install --prod --frozen-lockfile --ignore-scripts
node dist/cli/bin.js --help
```

The archive contains compiled output, corresponding TypeScript source, a locked dependency graph, an MIT license, the implementation specification, and synthetic examples. It does not contain `node_modules`, a Node runtime, caches, reports, or downstream project source.

## Known limits

The v0.1.0 benchmark labels remain provisional and do not establish a general accuracy rate. A missing reference does not prove migration, runtime non-use, or safe deletion. Automatic ecosystem discovery, CommonJS expansion, historical trend comparison, migration patches, npm publication, macOS validation, and verified third-party adoption are outside this release.
