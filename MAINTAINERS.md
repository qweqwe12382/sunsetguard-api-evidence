# Maintainers

## Primary maintainer

- [@qweqwe12382](https://github.com/qweqwe12382) — repository owner and primary maintainer.

The primary maintainer is responsible for issue triage, pull request review, release decisions, security coordination, and preserving the evidence and safety contracts in `docs/SPEC.md`.

## Maintenance process

- Bugs and bounded feature requests start in GitHub Issues.
- Code changes use pull requests and must pass the Linux and Windows CI matrix.
- User-visible behavior changes are recorded in `CHANGELOG.md`.
- Security-sensitive reports follow `SECURITY.md` and must not include private source or exploit details in public issues.
- New maintainers will be listed here only after they have accepted the role and demonstrated sustained project work.

Maintainer status is a statement of project responsibility. It is not evidence of third-party adoption or ecosystem usage.
